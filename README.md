## 🧠 Professional Focus

Cloud & Identity Security Engineer specializing in **Identity & Access Management (IAM), Least Privilege enforcement, and Zero Trust Cloud Architecture**.

I engineer platforms and architectures that:

- **Secure Identity & Privileged Access**: Implement Entra ID, PIM, Conditional Access, and JIT access workflows.
- **Enforce Infrastructure Security**: Automate cloud governance using Terraform & Policy-as-Code (OPA).
- **Hardened Cloud-Native Workloads**: Deploy and secure Azure Kubernetes Service (AKS) environments.
- **Digitalize & Automate Operations**: Build secure enterprise low-code applications (Power Apps, Power Automate, Power BI) with relational governance.
- **Defend Emerging Tech**: Research and secure AI/LLM interfaces, prompt defenses, and agentic identity boundaries.

My work bridges **Cloud Infrastructure, Identity Governance, and Enterprise Automation**  delivering end-to-end operational security.
